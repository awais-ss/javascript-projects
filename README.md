## Projects

### Kanban Board
Three-column board: To Do, In Progress, and Done.
- Add tasks to any column
- Delete tasks and copy task text to the clipboard
- Tasks are saved in localStorage and restored on reload

**Tech:** HTML, CSS, JavaScript, DOM manipulation, localStorage

### GitHub Profile Explorer
Search any GitHub username and see their public profile.
- Shows avatar, username, bio, followers, following, and public repository count
- Lists top repositories sorted by stars
- Press Enter to search; shows a message if the user is not found

**Tech:** JavaScript, async/await, Fetch API, GitHub REST API

### Guess the Number
Number guessing game with three difficulty levels.
- Easy (1-250, 7 attempts), Medium (1-750, 9 attempts), Hard (1-1000, 11 attempts)
- Higher/lower hints, attempt counter, and guess history
- Play the same level again or reset to choose a new one

**Tech:** HTML, CSS, JavaScript, DOM manipulation, event handling

### To-Do List
Simple task manager.
- Add, edit, delete, and copy tasks
- Clear all tasks at once
- Tasks are saved in localStorage

**Tech:** HTML, CSS, JavaScript, DOM manipulation, localStorage

### Typing Tester
30-second typing speed test.
- Characters turn green or red as you type
- Shows WPM, accuracy, correct and wrong character counts
- Best WPM is saved in localStorage
- Quotes are fetched from an API, with an offline fallback list
- Restart or load a new text at any time

**Tech:** HTML, CSS, JavaScript, Fetch API, localStorage, timers

## Run Locally

No installation needed.

```bash
git clone https://github.com/awais-ss/javascript-projects.git
```

Then open the `index.html` file inside any project folder in your browser.
