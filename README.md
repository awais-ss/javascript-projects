# JavaScript Projects

Small projects built with plain HTML, CSS, and JavaScript (no frameworks).

| Project | What it does | Tech |
|---|---|---|
| [Kanban Board](./kanban-board) | Three-column board (To Do, In Progress, Done). Add, delete, and copy tasks. Saved in localStorage. | HTML, CSS, JavaScript, localStorage |
| [GitHub Profile Explorer](./github-profile-explorer) | Search a GitHub username and see avatar, bio, followers, repo count, and top repositories. | JavaScript, Fetch API, GitHub REST API |
| [Guess the Number](./guess-the-number) | Number guessing game with three difficulty levels, attempt limit, and guess history. | JavaScript, DOM manipulation |
| [To-Do List](./todo-list) | Add, edit, delete, and copy tasks. Saved in localStorage. | JavaScript, DOM, localStorage |
| [Typing Tester](./typing-tester) | 30-second typing test with WPM and accuracy. Random quotes from an API with an offline fallback. | JavaScript, Fetch API, localStorage |
